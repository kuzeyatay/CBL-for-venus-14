# Venus GUI
A Vite app which uses MQTT communcation to map the Venus environment based on information recieved from the robots.

## Installation
1. Ensure node is installed by running `node -v`
2. Navigate to the gui directory and execute `node install`to install dependencies

## Usage
1. Run `node proxy.cjs` to start the mqtt websocket proxy
2. Run `npm run dev` to start the local site
3. Navigate to the address displayed in the terminal
