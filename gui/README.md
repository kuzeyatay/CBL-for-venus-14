# Venus GUI
A Vite app which uses MQTT communcation and a WebSocket bridge to map the Venus environment based on information recieved from the robots.

## Installation
1. Ensure node is installed by running `node -v`
2. Navigate to the gui directory and execute `npm install`to install dependencies

## Usage
1. Ensure [pc_recieve_ws.py](../comms/pc_recieve_ws.py) is running on the local machine
2. Run `npm run dev` to start the local site
3. Navigate to the address displayed in the terminal
